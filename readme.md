# Lazy Load for Comments - Speed Up WordPress Comments

Lazy Load for Comments is a lightweight WordPress plugin that defers loading the native WordPress comments until they are actually needed. Instead of loading every comment, avatar, and script with the rest of the page, the comments are loaded only when the visitor scrolls to them or clicks a button. This reduces HTTP requests and improves page load time.

## Features

- **On-Scroll & On-Click Loading**: Load comments automatically when the visitor scrolls to the comments area, or only when they click a button.
- **Block & Classic Theme Support**: Works with modern block themes (the Comments block) as well as traditional classic themes.
- **Improved Page Speed**: Skips comment avatars, scripts, and extra HTTP requests until the comments are actually requested.
- **SEO Friendly**: Comments are served normally to search engine crawlers, so they stay fully indexable.
- **Customizable Load Button**: Change the button text, switch between your theme's style or the plugin's style, and add your own CSS classes.
- **Developer-Friendly**: Built on a modern, hook-based architecture with a REST API, making it easy to extend.
